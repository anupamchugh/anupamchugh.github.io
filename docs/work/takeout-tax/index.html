takeout tax

Part obituary, part invoice: a local tool for measuring what it costs when a service you relied on disappears.

input

Google Takeout folder

output

migration-time invoice

privacy

local processing

the idea

Export a Takeout folder, point the CLI at it, and get an estimate of the files, products, migration hours, opportunity cost, and risk left behind by a product shutdown.

npx takeout-tax ~/Downloads/Takeout --rate 75

The companion “Where I Was” concept correlates service-death dates with places in an export. It remains an experiment, not a claim that the web app or an iOS app is shipped.

source

The implementation and full README live in the public repository. The scanner reads folder names and file metadata; it does not upload the contents of your export.
