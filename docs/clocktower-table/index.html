How web and iOS stay unified

The web companion uses the same script names, role catalog, player-group ideas, and prep flow as the iOS app. Live play stays host-led and local-first; the web surface is the browser-friendly control panel for setup, reference, and solo practice.

What it is not

It is not a generic pastel game page, and it is not an automated bot replacement for a storyteller. The AI tools stay in prep and rehearsal.
