## regression signals found

- Framework headings arriving before a lived scene.
- Repeated “the problem / the solution / the lesson” scaffolding.
- A new tool or HN thread treated as a reason to publish before the idea has changed shape.
- Cross-links creating a series-shaped feeling where no real series exists.
- Explanations that sound certain but do not name the observation that earned the certainty.
